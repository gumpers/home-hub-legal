Home Hub privacy policy

Effective 20 November 2026

Home Hub is a personal, single-user app built and used by Campbell Myott. It links Google Assistant to his own Home Assistant instance so he can control his own home by voice. It is not a commercial product and is not offered to anyone else. This policy explains what Google user data it touches and what happens to it. Read the Home Hub homepage for a description of the app.

Google user data Home Hub accesses

Home Hub accesses Google user data only through the Google Assistant SDK. The only scope it requests is the Assistant SDK scope that allows it to send commands to Google Assistant on behalf of Campbell's own Google account. It does not read his email, contacts, calendar, files, location or any other Google data.

How the data is used

The data is used only to send Campbell's own Assistant commands to his own Home Assistant instance and to return the result. It is not used for any other purpose.

What is stored

Home Hub stores OAuth tokens (an access token and a refresh token) on Campbell's own Home Assistant server. They are used only to talk to Google on his behalf. Nothing is stored on a third-party server or in any cloud service run by the developer. This website is a static page and collects no data, sets no cookies and has no analytics.

Sharing

Home Hub does not share Google user data with anyone. It does not sell it, does not use it for advertising, and does not use it to build profiles of any person. No one other than Campbell has an account or any access.

Google API Services User Data Policy

Home Hub's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting tokens

Campbell can revoke Home Hub's access at any time from his Google Account, under Security, then Third-party apps and services (myaccount.google.com/permissions). He can also delete the stored tokens from his own Home Assistant instance. Once either is done, Home Hub can no longer reach Google.

Changes

If this policy changes, the new version will replace this page and the date at the top will be updated.
