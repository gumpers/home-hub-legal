# home-hub-legal

Static homepage and privacy policy for Home Hub, Campbell Myott's personal single-user app that links Google Assistant to his own Home Assistant instance.

Published with GitHub Pages from the root of `main`:

- Homepage: https://gumpers.github.io/home-hub-legal/
- Privacy policy: https://gumpers.github.io/home-hub-legal/privacy/

Plain HTML and CSS only. `.nojekyll` makes Pages serve the files as they are.
